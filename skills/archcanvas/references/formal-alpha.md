# Historical formal Alpha reference

The former M3/M4 feature lists, fixed L0–L3 counts, black-and-white UI workflow,
and benchmark/study query-string instructions have been retired from this Skill.
They described the earlier formal Canvas interface and must not guide the
current Summary Studio.

Use [runtime-compatibility.md](runtime-compatibility.md) for runtime discovery,
formal Python authoring and transaction contracts, and
[visual-workflow.md](visual-workflow.md) for current graph editing and export.
Read the actual doctor's version and capabilities before using an installed
release; a historical package does not inherit development features.

Historical measurements and acceptance records remain under the project's
`docs/evidence` and versioned reports. They certify only their bound source/build
and do not establish current browser coverage, human usability, publication
quality or presented performance. The removal scope is documented in
[Summary legacy cleanup](../../../docs/summary-legacy-cleanup.md).
